# CoC7 — Fenêtre de jet thématique

Module Foundry VTT v14 pour le système **L'Appel de Cthulhu 7e (CoC7)**.

## Ce que fait le module
Il remplace la fenêtre qui s'ouvre avant un jet (difficulté, modificateur, dés bonus et malus) par une présentation plus claire :
- la **valeur du jet** en grand, avec l'image de la compétence et le nom de l'investigateur ;
- des **tuiles de difficulté** (Inconnue, Ordinaire, Majeur, Extrême) qui affichent leur seuil ;
- les **dés bonus et malus** en cinq crans (−2 à +2) au lieu du curseur ;
- les **chances de réussite** exactes, recalculées à chaque choix ;
- des raccourcis clavier : ← → pour les dés, 1 à 4 pour la difficulté, Entrée pour lancer.

La fenêtre prend les couleurs et les polices du thème du chat. Elle change toute seule quand le thème change, donc avec la bascule d'époque. Rien n'est modifié dans CoC7 : les champs d'origine restent dans la fenêtre, cachés, et le système lit ses valeurs comme d'habitude. Un réglage par joueur (« Nouvelle fenêtre de jet ») permet de revenir à la fenêtre d'origine.

Thèmes repris de « CoC7 — Cartes de chat thématiques » : Années 20, New York années 20, Par-delà les Montagnes Hallucinées, New York 2026, Antarctique 2026. 

## Nécessaire
- le système CoC7 (8.14 ou plus).

Recommandé : le module **CoC7 — Cartes de chat thématiques**, qui fournit les thèmes et les polices. Sans lui, la fenêtre garde une palette sombre neutre.

## Comment choisir le thème
Aucun réglage dans ce module : le thème est celui des cartes de chat (réglage « Imposer un thème » du MJ, que la bascule d'époque pilote déjà).
