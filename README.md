# CoC7 — Fenêtre de jet thématique

Module Foundry VTT v14 pour le système **L'Appel de Cthulhu 7e (CoC7)**.

## Ce que fait le module
La fenêtre qui s'ouvre avant un jet (difficulté, modificateur, dés bonus et malus) prend les couleurs, les polices et le style du thème du chat. Elle change toute seule quand le thème change, donc avec la bascule d'époque.

Thèmes repris de « CoC7 — Cartes de chat thématiques » : Années 20, New York années 20, Par-delà les Montagnes Hallucinées, New York 2026, Antarctique 2026. Sans thème actif, la fenêtre reste celle de CoC7.

## Nécessaire
- le système CoC7 (8.14 ou plus),
- le module **CoC7 — Cartes de chat thématiques** (il fournit les thèmes et les polices).

## Comment choisir le thème
Aucun réglage dans ce module : le thème est celui des cartes de chat (réglage « Imposer un thème » du MJ, que la bascule d'époque pilote déjà).
